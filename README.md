# MoRaj Ledger — downloads

The installers for **MoRaj Ledger**, double-entry accounting for Ghanaian businesses, schools and
NGOs. Open the latest release on the right (or below) and download the file for your computer:

| Your computer | File |
|---|---|
| Windows | `MoRaj-Ledger-Setup-<version>.exe` |
| Mac with Apple silicon (M1 and later) | `MoRaj-Ledger-<version>-arm64.dmg` |
| Mac with an Intel processor | `MoRaj-Ledger-<version>.dmg` |

**Already using MoRaj Ledger?** Take a backup first (Backup & Export, Back up now), then install the
new version over the old one. Your books are kept.

**New here?** A new installation runs as a 30-day evaluation with everything unlocked. A licence key
(Licence, under Administration) opens it for good — write to sales@morajconsult.com.

Each release lists a SHA-256 fingerprint for every file, so you can check what you downloaded.

This repository holds installers only — no source code.
